# Security

DiscordForge uses official Discord bot accounts only. Do not use a self-bot or normal user token.

Rules:

- Never commit `.env`.
- Never hardcode bot tokens or OpenAI keys.
- Rotate exposed Discord tokens immediately.
- Keep webhook URLs private.
- Do not grant Administrator unless you need it and trust the runtime environment.
- Review generated blueprints before applying them.
- Use dry-run mode before live setup.

Sensitive communities such as finance, trading, crypto, sports betting, gambling, legal, medical, and health should include a disclaimer channel and avoid guaranteed outcomes or individualized professional advice.
