# Permissions

Recommended bot permissions:

- Manage Roles
- Manage Channels
- Manage Webhooks
- Manage Messages
- Moderate Members
- Kick Members
- Ban Members
- Manage Server
- View Audit Log
- Send Messages
- Read Message History
- Embed Links
- Attach Files

The bot role must be higher than the roles it creates or edits. Discord does not allow a bot to manage roles at or above its own highest role.

Use Administrator only for private test servers or when you understand the operational risk.
