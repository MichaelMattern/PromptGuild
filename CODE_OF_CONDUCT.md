# Code of Conduct

## Our Pledge

PromptGuild is an open-source project for people building community tooling. We are committed to making participation welcoming, respectful, and productive for contributors of all experience levels.

## Expected Behavior

- Be respectful and constructive in issues, pull requests, reviews, and discussions.
- Assume good intent, but accept feedback when wording or behavior causes harm.
- Keep feedback focused on the work and the technical tradeoffs.
- Help new contributors understand project context and safety expectations.
- Respect privacy. Do not post bot tokens, API keys, webhook URLs, private server IDs, or screenshots containing secrets.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or behavior.
- Sexualized language or imagery.
- Trolling, sustained disruption, or bad-faith participation.
- Publishing private information or secrets without permission.
- Encouraging self-bots, token abuse, scraping, or Discord Terms of Service violations.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or limit participation when behavior violates this code of conduct.

If you need to report a concern, contact the repository owner privately through GitHub. Include relevant links, screenshots, and context when safe to do so. Maintainers will review reports respectfully and avoid sharing private details beyond what is needed to respond.

## Scope

This code of conduct applies in project spaces including GitHub issues, pull requests, discussions, documentation, community chat, and public interactions where someone represents PromptGuild.
