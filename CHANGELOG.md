# Changelog

## 0.1.0

- Added prompt-to-Discord blueprint generation with Ollama, OpenAI, auto, and local fallback modes.
- Added web UI for environment setup, prompt generation, YAML editing, validation, dry-run, and live provisioning.
- Added reusable blueprint templates under `blueprints/templates`.
- Added Docker and Docker Compose support.
- Added Discord bot setup, permissions, security, troubleshooting, and open-source release documentation.
- Added GitHub Actions CI for build, audit, example validation, and Compose config checks.
