# Contributor Task Ideas

Use this list to seed GitHub issues after launch. Each item is written to be copyable into an issue title with a short description.

## Good First Issue

1. Add a creator/community Discord server blueprint template.
2. Add a gaming clan Discord server blueprint template.
3. Add a sports analytics Discord server blueprint template.
4. Add more example prompts to the README.
5. Improve README screenshots for the web UI.
6. Add clearer empty-state copy in the web UI.
7. Add a classroom or online cohort Discord server blueprint template.
8. Add an open-source project Discord server blueprint template.

## Help Wanted

1. Improve web UI styling for blueprint preview and run logs.
2. Export generated blueprint as downloadable YAML from the web UI.
3. Add slash-command support for approved blueprint generation.
4. Add a template marketplace concept document.
5. Add import/export support for reusable template packs.
6. Improve provider fallback messages when Ollama or OpenAI is unavailable.
7. Add richer permission preview summaries before live setup.

## Documentation

1. Improve Docker quickstart docs.
2. Add an architecture diagram.
3. Add "How PromptGuild works internally" documentation.
4. Add a guide for writing new blueprint templates.
5. Add a provider comparison page for OpenAI, Ollama, auto, and local modes.
6. Add troubleshooting examples for Discord role hierarchy errors.
7. Add screenshots for the web UI setup checklist.

## Feature

1. Add downloadable YAML export.
2. Add blueprint diff view between current server state and generated plan.
3. Add template tags and search in the web UI.
4. Add generated blueprint naming suggestions.
5. Add a safer confirmation flow for live setup changes.
6. Add webhook integration examples for changelogs, support, and alerts.
7. Add onboarding prompt guidance for manual Discord setup.

## Testing

1. Add tests for blueprint validation.
2. Add tests for deterministic local generation.
3. Add tests for provider auto mode fallback order.
4. Add tests for dry-run plan output.
5. Add tests for permission overwrite validation.
6. Add tests for idempotent role/channel provisioning helpers.
7. Add example blueprint validation to CI.
